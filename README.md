# Installation Guide
This guide will help you set up and install the necessary components for your project.
## Prerequisites
- Python 3.13 installed on your system.
- Ensure you have `pip` installed for managing Python packages.
- Ensure you installed ``uv`` via ``pip install uv`` on your global Python environment.
## Installation Steps
1. **Clone the Repository**: If you haven't already, clone the repository containing the project files.
2. **Run the Server**: In the root directory of the project, run the following command to start the server:
   ```bash
   uv run main.py
   ```
